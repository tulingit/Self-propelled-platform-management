# Self-propelled-platform-management
Control of an Arduino-based self-propelled platform

Данный код предназначен для работы с драйвером L298N и другими его типами.
Также в данном коде реализовано управление через ИК-пульт, но вы можете использовать любой другой способ управления.
Не забывайте менять в коде значения кнопок вашего пульта управления.
